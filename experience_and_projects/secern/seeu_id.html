SeeU ID (May 2024 ~ November 2024)

Client: Indo China Bank, TriNam

Affiliation: SECERN AI

In this project, we developed an ID card detection and recognition system called SeeU ID. SeeU ID consists of OCR, image detection, face detection, and face recognition. The purpose of the task is to read the information from ID and verify the authority or accessibility for security.

The integrated system achieved 96.24% accuracy.

1. ID card detection with segmentation

To read the information, ID card must be detected. Because an ID card may not be placed in the correct orientation, we detected it using a segmentation model and after many reviews, we chose YOLOv11 segmentation model for this task.

We achieved 98.47% accuracy in the test dataset.

2. Alignment of ID card

To improve the accuracy and ease of text detection and recognition, we applied image alignment to the ID-card image produced by the segmentation model.

3. OCR

OCR model is used for this task. OCR model consists of text detection and recognition. We tested and evaluated models and the DBNet and SVTR models were chosen.

We achieved 97.89% for detection of text and 98.82% for recognition.
