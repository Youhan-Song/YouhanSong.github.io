Tanzania SmartGate (January 2024 ~ December 2024)

Client: CUPIA, Tanzania Customs Service

Affiliation: SECERN AI (AI Team 3)

In this project, we developed an automatic gate pass system called SmartGate with AI models. The system consists of Object Detection Model, OCR and face recognition. For Object Detection, It detects license plate and Container number area, and OCR then detects and recognizes the results from detection. And the face recognition system consists of face detection and face recognition. Face detection is to detect and crop the face. With this result, face recognition would compare the result to one of the list registered in the database. After comparing and verifying the identity, vehicle number, and container number, the gate would automatically open and the record will be stored in the database.

Tech Stack: Python, PyTorch, ONNX, OpenVINO, Linux, Docker, Slurm

My Responsibilities:

  • Established data collection guidelines and labeled local-environment data
  • Developed license plate / container region detection and OCR models
  • Wrote the multi-model integration algorithm (perception module integration SW)
  • ONNX / OpenVINO model lightweighting and on-site deployment

Key Achievements:

  • License plate / container region detection: 97.82%
  • Text detection: 94.28% · recognition: 92.35%
  • ONNX / OpenVINO lightweighting → real-time on-site deployment at the port
  • Tanzania Customs Service PoC completed successfully

1. LPR (License Plate Recognition) & CNR (Container Number Recognition)

To accomplish this task, the object detection model was used to detect the license plate and container number region to make OCR model can read the text easily with high accuracy. For this, we tested and decided to employ YOLOv11 model since it has higher speed and accuracy. Likewise, we tested many different models and their combinations related to the OCR and decided to use the DBNet and SVTR models.

We achieved 97.82% for detection of License plate and container area and 94.28% for detection of text in license plate and container, and 92.35% for recognition.

Challenge & Solution: The port gate is an outdoor environment with non-standard conditions (lighting, angle, weather). We directly collected and labeled local-environment data for domain adaptation to secure environmental diversity in the training dataset. In addition, multiple AI models (license plate, container, OCR) had to run simultaneously with real-time processing, so we unified each model's input/output and designed a single integrated pipeline SW to secure real-time performance.

2. Face Detection & Recognition

To build a face recognition system, face detection and recognition model is needed. To select a suitable model, we considered many factors such as accuracy, speed, computational cost, and so on. Finally, we chose to use YOLOv11 which has a better performance than others. And for face recognition, we compared many kinds of feature extraction algorithm, and head algorithm to output the proper result. After many trials, we chose ResNet101 for feature extraction and sub-center ArcFace as the classification head.

We achieved 97.84% accuracy for average of detection and recognition.

3. System Integration

Finally, we integrated every AI model into a single script to verify and provide the entire system to customer.

The final accuracy of the integrated system is 90.85%
