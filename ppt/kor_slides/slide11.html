Project 11 Autonomous Driving Perception

Autonomous Vehicle for All (AVA)

Traffic Sign & Signal Detection for Autonomous Vehicle

Texas A&M Texas D.O.T (텍사스 교통국)

2022.05 - 2023.08

Project Goal

Texas D.O.T 후원 연구 과제로 UIUC, UC Davis와 공동 수행. 미국 도시 외곽/비포장(Rural/Off-road) 환경의 자율주행 시스템 개발 과제에서 교통 표지판/신호등 인지 모듈 개발과 ROS 기반 실차(Jeep Grand Cherokee) 통합까지 수행했습니다.

Key Responsibilities

  • Multi-sensor(Camera, LiDAR, Radar, GPS+IMU) 데이터 수집·라벨링
  • Traffic Sign/Signal Detection 모델 개발
  • ROS 환경 통합 및 실시간 추론 파이프라인 구축
  • 실제 자율주행 차량 탑재 및 실증 테스트

Key Achievements

  • Texas 현지 도로 환경에 맞는 자체 데이터셋 구축
  • 조도·날씨·가려짐에 강인한 표지판/신호등 탐지 모델 개발
  • 차량 제어 시스템과의 실시간 연동 파이프라인 구축
  • 데이터 수집부터 모델 설계·학습, 차량 탑재·테스트까지 전 과정 수행
